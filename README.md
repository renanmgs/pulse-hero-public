# Pulse Hero Public Site

Static public website for Pulse Hero store release materials.

## Pages

- `index.html` - landing page.
- `privacy-policy.html` - English privacy policy for app store review.
- `delete-account.html` - public account deletion instructions.

## GitHub Pages

Recommended repository name: `pulse-hero-public`.

Use GitHub Pages with:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

The default GitHub Pages URL should be:

`https://renanmgs.github.io/pulse-hero-public/`

When a custom domain is ready, point the same repository to a subdomain such as:

`fithero.charactercraftapp.com`

## Store URLs

Use these URLs while hosted on the default GitHub Pages domain:

- Privacy Policy: `https://renanmgs.github.io/pulse-hero-public/privacy-policy.html`
- Delete Account: `https://renanmgs.github.io/pulse-hero-public/delete-account.html`
